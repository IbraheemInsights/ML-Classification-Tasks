# ML Classification Tasks

This repository contains 4 Machine Learning classification tasks 
completed as part of an AI internship (Adobe x Krunatic).

## Tasks
- **Task 1:** Random Forest Classifier — Breast Cancer Detection
- **Task 2:** Logistic Regression — Diabetes Prediction
- **Task 3:** XGBoost Classifier — Titanic Survival Prediction
- **Task 4:** Decision Tree Classifier — Diabetes Prediction

## Workflow
Each task follows a strict 12-step ML workflow:
1. Problem Understanding
2. Data Collection
3. Data Cleaning
4. Data Preprocessing
5. Exploratory Data Analysis (EDA)
6. Feature Engineering
7. Train-Test Split
8. Model Selection
9. Model Training
10. Hyperparameter Optimization (GridSearchCV)
11. Model Evaluation
12. Model Deployment

## Tools & Libraries
Python, Scikit-learn, XGBoost, Pandas, NumPy, Matplotlib, Seaborn, Joblib

## Datasets
- Breast Cancer Wisconsin (sklearn built-in)
- Pima Indians Diabetes Dataset
- Titanic Passenger Dataset

## Results
| Task | Model | Accuracy | ROC-AUC |
|------|-------|----------|---------|
| Task 1 | Random Forest | 95.61% | 0.9950 |
| Task 2 | Logistic Regression | 70.78% | 0.8130 |
| Task 3 | XGBoost | 77.65% | 0.8235 |
| Task 4 | Decision Tree | 68.83% | 0.7527 |
